# I6 联调与发布门禁记录

日期：2026-11-16。I6 的自动化联调和模拟器检查已实施；**发布验收尚未全部完成**：当前没有可用真机，也没有接入真实云文档提供者或 TalkBack 服务，不能用模拟器结果替代这些检查。

## 自动化范围

| 项目 | 验证内容 |
| --- | --- |
| 连续主流程 | 通过 Android 系统文件选择器选择 Debug 测试文档，从 F30 裁剪、增强、保存并返回录音库；核对版本来源、原文件不变和实际导出字节。 |
| 文档异常 | Debug 测试提供者模拟权限拒绝和提供者不可用；不创建项目，允许重新选择。提供者的大小字段为未知；它是本地测试替身，不代表真实云服务。 |
| 真实进程中断 | 在 SDK 测试包真实复制文件的第二次读取处阻塞，使用 `am force-stop` 杀掉该进程，重启后验证 COPYING 状态被识别、该操作专属的残留目录被清理、没有项目被误提交。 |
| 格式和边界 | 运行 SDK 导入、异常恢复、M4A 裁剪、WAV/M4A 导出与数据库迁移测试；既有测试还覆盖无效音频、并发、空间不足和提交边界。 |
| 界面和生命周期 | 浅色/深色、1.3 倍字体、横竖屏切换、页面重建、顶部栏、手柄虚拟无障碍节点、选区及输出版本选择。节点检查不等同于 TalkBack 实测。 |
| 测试隔离 | 文件和项目由测试生成并清理；文档提供者仅存在于 Debug 构建，Release 合并清单不包含它。真实进程中断脚本只操作明确指定设备的 SDK 测试包。 |

可在隔离设备安装 `soundly-sdk-debug-androidTest.apk` 后运行：

```bash
scripts/verify_i6_process_recovery.sh <adb-device-serial>
```

脚本会强制停止 `com.ideacode.soundly_sdk.test`，请使用专门的测试安装。

## 测试环境及结果

- Android 8（API 26）：SDK 回归 26 项通过；导入、裁剪、增强、导出、顶部栏等 App 回归 10 项通过；系统选择器连续链路、横屏与裁剪无障碍节点测试 2 项通过，使用 1.3 倍字体；实际复制中强制终止和恢复通过。测试包使用旧版存储权限，授权后执行公共下载目录相关测试。
- Android 13（API 33）：SDK 回归 26 项、App 回归 13 项通过，覆盖系统选择器连续链路、文档异常、横屏、裁剪无障碍节点、导入预览、增强、导出及顶部栏。
- Android 15（API 35）：SDK 回归 26 项、App 回归 11 项通过；系统选择器连续链路、文档异常、横屏和裁剪无障碍节点测试通过，包含系统栏检查。
- Debug 构建、App/SDK 单元测试和 App lint 通过；核对 Release 清单不含测试文档提供者。

## 待完成的发布验收

1. 在至少一台真实 Android 设备上验证麦克风未授权时的导入、各入口返回、长文件播放、双手柄触控、分享目标读取、保存到下载目录及电量/空间异常；记录机型、系统版本和结果。
2. 用真实云文档提供者验证未缓存、未知大小、慢速、断网、权限撤销和重新授权；确认导入完成后本地副本可脱离原 URI 工作。
3. 打开 TalkBack 实测裁剪双手柄的焦点、范围、读数与操作，核对大字体、深浅主题和横屏；再在不同尺寸设备上检查系统栏遮挡。
4. 在真实设备的复制和提交附近进行进程终止验证，覆盖导入、增强、导出结果不明的提示与人工核验。当前自动测试只在模拟器和受控复制边界执行，不代表所有时间点或外部 provider 已验证。
5. 验证真实 AAC/MP3/M4A 来源、设备解码器、不同采样率及异常编码；WAV 裁剪按采样帧对齐，M4A 裁剪受编码帧边界影响。完成后补充证据并由项目负责人决定发布。
