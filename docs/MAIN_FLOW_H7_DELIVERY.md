# 主流程 H7 交付记录

## 页面与行为

- F24 按项目和当前选中版本加载信息，提供本次文件名、格式和只读保存位置；文件名不修改项目名。格式扩展名跟随格式，名称不合法时提示修改。
- 输出固定保存在 `Download/Soundly`；同名时自动编号。页面展示 SDK 返回的真实进度，保存中禁止重复提交和同时分享，错误按可重试性提供处理方式。
- F25 展示 SDK 实际返回的文件名、格式、大小和所选版本信息，可打开已保存文件或返回录音库。页面支持浅色和深色主题。
- 系统分享使用录音库中的**所选源版本**，不是导出后可能经过转换的文件；界面明确提示这一点。打开分享面板不代表发送成功。
- Android 8～9 导出需要外部存储读写权限，拒绝后提供说明和设置入口；较新系统使用平台的共享存储机制。

## 格式与恢复

格式选项与 SDK 当前能力一致：WAV 源可导出 WAV；M4A、AAC、MP3 源可保留源格式或转换为 PCM WAV；未知格式不可导出。设置中的默认格式仅用于初始化，不可用时回退到实际可用格式并提示，单次选择不会改变全局设置。解码或存储仍可能失败，由页面展示错误。

页面 ViewModel 负责状态和业务编排，Fragment 负责渲染、权限和系统界面；导出经 UseCase 和 Gateway 调用 SDK。私有导出记录保存进行中状态和 SDK 返回的真实结果。恢复时先检查文件 URI，不会自动重复导出；若进程在文件写成但结果 URI 尚未记录时终止，无法确认结果，页面提示检查下载目录后由用户决定如何处理。
