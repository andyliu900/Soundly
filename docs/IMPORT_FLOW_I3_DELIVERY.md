# I3 交付记录：F17 首尾裁剪

## 范围

- F17 根据设计稿重做，支持浅色和深色主题、固定顶部栏、真实音频波形和双端选区。可拖动手柄，也可通过起点、终点输入精确时间；选区无效时不能应用。
- 试听从选区起点开始，并在终点停止并回到起点；改变范围、离开页面或应用时停止试听。页面重建后保留选区。
- WAV/M4A 裁剪生成独立版本并保留源音频；完成后返回原预览页并选择新版本，后续导出和增强使用该版本。AAC/MP3 当前给出不支持直接裁剪的提示。
- 执行中禁止重复提交和返回；失败保留选择。通过持久化操作记录处理进程中断：已确认且文件可读的结果可以恢复，结果不明时提示用户检查录音库并自行确认是否继续，不自动重新裁剪。
- UI 状态和协程由 ViewModel 管理，Fragment 负责交互与导航；项目、播放器和裁剪能力经 Gateway 调用 SDK。SDK 在数据库提交结果不明时保留可能已入库的音频，避免误删。

## 验证

- `:soundly-app:assembleDebug`、App/SDK 单元测试及 `:soundly-app:lintDebug` 通过。
- Android 13 模拟器：F17 双手柄拖动、精确输入、旋转重建、选区试听、日夜主题、应用及返回，核对新版本来源、时间范围、导出目标、原文件不变和 WAV PCM 片段完全一致；另运行预览、增强、导出、主流程和顶部栏回归，共 10 项通过。
- Android 8 模拟器以 1.3 倍字体完成 F17 同一端到端流程，页面内容可滚动访问。
- Android 13 SDK 仪器测试 13 项通过；Android 8 SDK M4A 仪器测试 2 项通过。M4A 验证编码帧、输出时长和播放，并覆盖数据库提交后取消的文件保留。

## 精度与后续验收

WAV 按采样帧对齐裁剪；M4A 直接封装已有编码帧，边界受编码帧限制。试听停止时间受 Android 播放器 seek 和调度影响，不保证逐毫秒精确。若进程在操作记录清除与导航之间异常终止，用户可能需要在录音库检查已生成版本。多机型、不同编码器、无障碍服务及真实设备仍需 I6 验收；增强来源与 AB 对比已在 I4 实施；导出闭环和设备验收按 I5～I6 继续实施。
