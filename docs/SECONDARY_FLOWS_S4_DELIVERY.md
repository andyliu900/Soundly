# S0 → S4 设置、隐私和帮助交付

日期：2026-11-16。规则基线见 [S0 契约](SECONDARY_FLOWS_S0_CONTRACT.md)。

| 页面 | 本次实现 |
| --- | --- |
| F31 设置 | 按音频、数据与隐私、支持及外观分组；保留深色、浅色、跟随系统选择。 |
| F32 录音设置 | 场景单选及说明、录音质量、本机支持的 M4A/AAC 录音格式、后台录音开关；保存后反馈并返回，未保存的页面选择在重建时恢复。 |
| F33 输出设置 | 只提供 WAV/M4A/AAC/MP3 偏好和中文命名策略；保存后返回。实际导出格式仍取决于所选音频和 SDK 转换能力，不支持的偏好会回退到可用格式。 |
| F34 存储管理 | 展示原始、派生、缓存、恢复及其他数据和设备可用空间；清理缓存和删除数据均需确认，保留 SDK 正在录音及其他操作的互斥保护。 |
| F35 隐私与数据 | 说明本机处理、导出及诊断数据边界，增加存储管理入口和删除确认。 |
| F36 帮助与反馈 | 可展开 FAQ、编辑问题内容、选择是否附带应用版本、Android 版本和设备型号；仅打开邮件草稿，由用户确认发送。 |
| F37 Pro | 展示规划方向和暂未开放购买，可返回设置；没有购买或恢复购买入口。 |

SDK 删除全部本地数据会删除 SDK 管理的项目、音频及恢复数据并重置音频设置；导出的独立文件不受影响，App 外观及引导偏好不会被重置。存储统计含恢复及其他辅助文件，统计范围以 SDK 文件存储为准。

反馈收件地址尚未提供，`s4_feedback_recipient` 当前为空：打开邮件草稿时提示用户填写收件人。获得已确认地址后可在该资源中配置；未虚构任何联系方式。

验证包括 App/SDK 单元测试、App lint、Android 13 模拟器浅色设置、录音保护、主流程及导出回归，另运行深色设置流程。页面使用日夜主题资源；设计稿的图标和精确排版仍需产品视觉验收。邮件客户端兼容性、真机中断、横竖屏、大字体及无障碍完整验收属于 S6，模拟器结果不能代替真机验收。
