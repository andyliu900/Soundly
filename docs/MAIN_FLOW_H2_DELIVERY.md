# H2 启动、引导和首页交付

## 范围

- F01：复用启动协调器，根据 SDK 初始化、引导完成状态和活动录音分流，初始化失败可重试。
- F02：完成首次引导并持久化，导航时移除引导历史栈。
- F03-A/F04：展示首页空状态或 SDK 的最近项目，支持进入项目详情、录音库、设置和音频导入；项目变化通过 Flow 更新。
- F03-B：选择本次录音场景，草稿随状态恢复，传递给录音准备页，且不改写全局默认值。
- 顶层底部导航只在首页、录音库和设置展示；活动录音恢复前台时回到录音页。录音保存后移除已结束录音页。

## 验证

- `:soundly-app:testDebugUnitTest :soundly-app:assembleDebug :soundly-app:lintDebug` 通过，Android Test APK 可构建。
- Android 13 模拟器手动验证首次引导进入首页、场景选择及开始录音、保存后最近列表刷新、录音库和设置切换及返回首页。
- 录音期间点击系统通知回到录音页；保存项目的 SDK 数据中场景为 `MEETING`，与首页选择一致。
- 首页及场景弹层截图：[首页](screenshots/h2-home.png)、[场景选择](screenshots/h2-scene.png)。

## 阶段边界

F05/F06/F07 权限与录音准备的完整交互和视觉属于 H3；录音页、预览、增强与导出分别属于后续阶段。当前录音和预览页面仍使用已有功能界面。尚需在 H8 进行真机、不同系统版本及完整主流程验收。
