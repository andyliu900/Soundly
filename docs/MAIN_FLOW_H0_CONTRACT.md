# 主流程 H0：业务、状态与接口契约

状态：H0 实施基线，2026-11-15。适用模块 `:soundly-app`，技术栈为 Kotlin、Fragment、XML/ViewBinding、Material 3、Navigation 和协程 Flow；音频业务由 `:soundly-sdk` 提供。本文定义 H1～H8 的目标行为；表中的目标不代表对应高保真页面已实现或设备验收通过。

参考：[主流程实现里程碑](MAIN_FLOW_IMPLEMENTATION_MILESTONES.md)、[F01～F38 用户流程](../ProjectUI/用户操作流程与设计稿索引.md)、[设计完备性评审](../ProjectUI/UI设计稿完备性与实现准备评审报告.md)。本文是已冻结的 M0 功能版基线之上的**主流程增量契约**；如两者的迁移边界不同，以本文件记录的具体增量为准，M0 其他功能保持原有范围。

## 1. 范围、事实来源与架构边界

主线为 F01 → F02（首次）→ F03/F04 → F05/F06（需要权限时）→ F07 → F08/F09 → F15 → F18/F19 → F22/F23 → F24/F25。F10～F14、F20/F21 是保护路径；F16、F27 按入口复用，F38 是 F08 的深色状态。导入、裁剪、完整设置与录音库高保真实现仍按后续阶段进行，现有能力不因本契约删除。

| 数据/动作 | 唯一事实来源 | App 责任 |
|---|---|---|
| 引导完成、权限申请历史 | App 偏好及 Android 权限状态 | 显示和路由；每次返回系统设置后重新检查实际权限 |
| 会话、时长、字节、标记、实时波形、中断 | SDK recorder 的 state、markers、waveform | 只映射为显示；不能用屏幕计时器伪造保存内容或结果 |
| 项目、版本、静态波形、播放状态 | SDK project/recorder/playback | 始终以 projectId/variantId 对应版本读取和操作 |
| 增强任务、阶段、进度和结果 | SDK enhancer observe(taskId) | 用户动作发起一次；同进程重建重新观察；不可伪造效果摘要 |
| 导出进度、输出文件 | SDK exporter 的进度与 ExportResult | 根据源格式过滤选择，以成功返回的名称、格式、URI 展示；不假定分享已完成 |
| 录音默认、输出偏好 | SDK settings | 仅作初值；单次覆盖不修改默认设置 |

架构方向：`Fragment / XML → 页面 ViewModel (UiState / UiAction / UiEffect) → 按业务需要的 UseCase/Policy → Gateway → SDK`。当前部分 Fragment 仍直接调用 Gateway，属于 H1～H7 迁移项；不要宣称本次已完成全部页面的 ViewModel 改造。平台授权、文件/分享选择器由 Android 控制器或 Fragment 处理，结果作为动作回到 ViewModel。SDK 音频处理、文件和数据库逻辑不在 App 层复制。

## 2. 单次录音参数契约

| 字段 | 规则 |
|---|---|
| 场景优先级 | F07 本次选择 > 首页 F03-B 本次选择 > SDK 持久化默认。未做选择时维持默认；首页/准备页选择只影响此次会话 |
| 音质 | F07 本次选择 > SDK 默认；录音格式及后台通知使用 SDK 默认。F07 手机麦克风为展示值，不承诺设备选择 |
| 标题 | 去除首尾空白；空值按 SDK 命名设置和创建时刻生成。具体长度由 SDK 校验；不可将标题回写全局默认 |
| UI 场景映射 | 自动→`AUTO`、会议→`MEETING`、课堂→`CLASSROOM`、采访→`INTERVIEW`、语音备忘→`OTHER`；`OTHER` 是元数据映射，不宣称 SDK 有独立语音备忘 DSP |
| 生命周期 | 草稿只属于一次新建流程；页面重建恢复草稿，成功创建会话后不重放开始指令。录音相关状态以 SDK session 为准 |

实现位置：`RecordingDraft.toConfig`、`RecordingScenario`。现有 F07 已使用 `RecordingDraft` 和 SDK 默认设置构建配置；F03-B/F07 的可编辑控件与跨页草稿传递在 H2/H3 落地。`prepare(config)` 与 `prepareUsingDefaults` 共存，不移除原 SDK 接口。

## 3. 增强模式契约

| 产品模式 | SDK `PresetOption` | 处理依据和呈现边界 |
|---|---|---|
| 自动增强（默认、一键） | `AI` | SDK 分析音频特征后进行自适应音色/动态处理及 RNNoise 降噪；具体结果依赖音频，不能保证每一项效果 |
| 清晰人声 | `SPEECH_FOCUS` | 固定人声清晰优先预设，含降噪与动态处理 |
| 降低噪声 | `DEFAULT` | 固定默认处理预设，含传统降噪与音色/动态处理；名称表示处理方向，不承诺降噪强度高于其他模式 |
| 自然平衡 | `NATURAL_SMOOTH` | 固定自然顺滑预设 |

以上映射是产品层选择，SDK 其他 preset 保留可供后续扩展。`EnhancementMode` 是主流程映射事实来源，F18 当前功能页已改为这四项。F15 一键入口尚需在 H5 实现并使用同一 `EnhancementMode.default`。F22/F23 展示模式和“处理方向”，不静态宣称“已降低噪声”等检测结论；公开结果没有逐项效果测量字段。

开始增强必须传 `(projectId, sourceVariantId, preset)`；创建成功以 SDK 返回的 taskId 观察。新增强生成独立版本，不覆盖输入。取消成功、失败与成功均为终态；重试只有在 SDK `retryable` 时允许，并使用新 taskId。SDK 仅承诺当前进程内任务可观察：进程消失后重新查询项目，若任务未知且无已完成版本，说明中断并允许用户重新发起，不自动创建新任务。

## 4. 导出与分享契约

| 原始版本格式 | `AUTOMATIC` 可选输出 | 默认偏好不在可选项时 |
|---|---|---|
| WAV | WAV（复制原文件） | 回退 WAV，并在界面展示实际格式 |
| M4A、AAC、MP3 | 与源格式相同（直接复制）；WAV（解码为 PCM16） | 回退源格式，并说明偏好未应用 |
| UNKNOWN | 无可用项 | 禁用导出并说明格式无法识别，不靠扩展名猜测 |

这是对当前 SDK `ExportQualityPolicy` 的 UI 层保守筛选，`ExportFormatOptions` 实现该表。实际导出仍由 SDK 决定是否支持并可能因解码、存储或输入文件损坏而失败；SDK 格式能力调整时必须同步该策略及测试。源格式为 WAV 且同格式自动导出时保留原容器，不声称强制转 PCM16。

F24 的数据输入为 projectId 与**当前选中版本** variantId。文件名仅本次使用，不更改项目名；输出格式以设置偏好作为初值，仅允许表中选项。首轮目标固定 `Download/Soundly`，显示为只读。冲突策略 `RENAME`，成功页显示 SDK 返回的 `displayName`、`format`、`destinationUri`，不得显示预期名称冒充真实结果。SDK `export(request, onProgress)` 已由 App Gateway 暴露；原 `exportToDownloads` 保留兼容当前页面。F24 的文件名校验、格式选择、进度和 F25 成功 UI 将在 H7 接入。

分享复用 SDK `prepareShare`：分享所选源版本，保持源格式，不应用默认输出格式；保存成功后如同时提供分享，文案须说明分享的是源版本。打开系统分享面板不等于接收方已保存或发送。若产品要求分享刚导出的转码文件，须增加不同的 URI 分享契约，不可复用源版本接口冒充。

## 5. 路由与页面状态契约

同一行的 F 编号可由同一个 Fragment 的不同状态表示。下表为目标；带“系统”的界面由 Android 提供。

| 页面与输入 | 稳定状态 / 可执行动作 | 成功去向 | 失败、取消和返回 |
|---|---|---|---|
| F01，无输入 | loading、初始化/恢复查询错误；失败可重试 | 活动会话优先 F08；否则可恢复 session → F14；否则首次 F02、回访 F03/F04 | 错误停留并重试；成功时将 F01 从返回栈移除，不绕过恢复查询错误 |
| F02 | 引导；开始使用持久化完成 | F03/F04 | 系统返回退出应用；后续启动不重复引导 |
| F03-A/F04、F03-B | 最近项目空/有数据；选择本次场景；开始录音 | 已授权→F07；未授权→F05 | 取消场景选择保留原值；近期项目/已有导入、库、设置入口保持 |
| F05/F06 | 解释、系统授权、普通拒绝、永久拒绝；请求权限或设置 | 已授权回 F07；通知权限独立于麦克风 | 可取消回首页；拒绝后可继续既有导入；设置返回仅重新检查，不自动开始录音 |
| F07，默认＋草稿 | 准备、开始中、防重、失败 | 一次 prepare/start 成功→F08 | 权限、音源、空间或准备失败留页可处理；返回上页不新建 session |
| F08/F09/F38，活动 session | 录制、暂停、中断、封装、失败；标记、暂停/继续、完成 | 完成并保存成功→F15，携带项目 ID、原始版本 ID | 点击返回→F11；保存中防重复；失败不能假报成功；前后台不重新开始 session |
| F10 | 系统通知展示录制/暂停、暂停/继续、停止保存 | 通知点击打开当前会话 | 系统/SDK 通知样式因版本变化；通知权限被拒不等于麦克风权限被拒 |
| F11 | 返回录音、结束并保存、放弃 | 保存成功→F15；放弃成功→首页 | 继续回到触发确认时的录音状态；放弃失败保留错误及当前内容；三动作视觉需补稿 |
| F12/F13，SDK 中断原因 | 按真实原因显示重试/保存；不足空间可查看现有存储入口 | 可恢复且重试成功→F08；保存成功→F15 | 不承诺所有中断均可继续，失败保留可恢复内容；不伪造剩余空间 |
| F14，可恢复 sessionId | 恢复中、成功、失败；恢复保存或丢弃 | 恢复成功→F15；丢弃成功→首页 | 逐个处理真实 session；失败留页。SDK 是否支持按指定 session 丢弃需在 H4 核实；不能误丢活动会话 |
| F15/F16，projectId＋variantId | 项目加载、播放/暂停/定位、重命名、原音直接导出、选增强/一键增强 | 一键→F19；调整→F18；导出→F24 | 缺少所选版本应错误提示，不能静默换成别的版本；重命名失败保留原名 |
| F18，projectId＋sourceVariantId | 四模式、当前选中、提交中 | 一次提交成功→F19，携带 taskId | 提交失败留页；返回 F15；快速重复点击不得创建多个任务 |
| F19/F20/F21，taskId | running、取消确认/取消中、失败、完成、取消；进度来自 SDK | 成功→F22，传 projectId、输入和输出版本 ID | F20 可继续/取消；可重试错误生成新 taskId；不可重试不展示可点击重试；返回不能重复消费终态 |
| F22/F23，projectId＋输入/增强版本 ID | 版本选择、播放/暂停/定位、切换中/错误 | 导出当前选中版本→F24；创建其他版本→F18 | AB 同位置，播放/暂停状态保持；切换失败恢复原选择并提示；返回项目上下文 |
| F24/F25，projectId＋selectedVariantId | 配置、导出中、错误、成功；本次文件名/格式，分享 | 真实导出成功→F25；返回 F27 | 防重复提交；失败可重试且不删除项目；分享不宣称发送成功；返回不重新执行导出 |

F15、F18、F19、F22、F24 之间导航必须保留准确的 sourceVariantId；现有 `originalVariantId` 参数在增强结果页实际代表“本次输入版本”，不一定是项目最初原音。缺参、版本被删或 taskId 失效需显示可恢复错误，禁止用第一个版本替代。

## 6. 生命周期、并发和可观测状态

- Fragment 持有视图与平台交互，绑定随 view 生命周期释放；使用 `repeatOnLifecycle(STARTED)` 观察可恢复状态，不把开始录音、增强或导出动作放进重启收集的代码块。
- ViewModel 使用 `StateFlow` 表达当前状态、接收动作，通过合适的作用域持有会话 ID、taskId 和操作状态；用 `SavedStateHandle` 存轻量参数，波形/音频文件不放入 Bundle。
- 后台完成可被恢复；导航使用 destination 校验和明确消费策略，不能因为收集器重订阅而重复导航/弹窗，也不能依赖无重放事件导致后台完成被丢失。
- prepare/start、stop/save、提交增强、取消、导出分别按业务互斥，按钮状态和数据层操作锁均须防重；重复点击不能创建额外 session、增强任务或文件。具体实现按 H3/H4/H6/H7 分阶段完成。
- SDK recorder 前台服务拥有录音生命周期，界面 STOP 不暂停它。增强任务按 SDK 当前进程生命周期处理。导出开始后在可维持操作的作用域内执行，进行中返回时阻止离开或明确提示；不承诺后台自动恢复或自动重导。
- 临时性错误可重试；权限或不支持格式给具体补救；不可重试错误不伪装可重试。UI 展示安全的本地化错误，不显示底层异常和私人路径。
