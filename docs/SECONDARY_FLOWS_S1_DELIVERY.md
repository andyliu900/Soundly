# S1 后台录音与异常保护交付

## 已实现

- F11 按 S0 契约先暂停，再显示“返回录音”和“放弃录音”两个操作；取消或返回后保持暂停。弹窗与会话 ID 绑定，跨重建保留；暂停失败不展示确认，系统返回/遮罩等同返回录音。弹窗使用真实时长和文件大小，适配深浅主题和可滚动布局。
- 后台录音开启时沿用前台服务。通知的暂停、继续和保存均绑定生成该通知的 session ID，SDK 在录音操作锁内验证，过期通知不能控制其他会话。关闭后台录音时，应用整体进入后台后暂停当前会话，回前台不自动继续；活动重建和应用内页面切换使用延迟窗口避免误判。暂停失败会在返回录音页时提示。
- F12/F13 保留按真实中断原因重试或保存的路径；低空间显示 SDK 查询的实际可用空间与已录大小，提供查看存储空间、保存当前录音，返回时不自动继续。F14 沿用按 session 恢复/放弃和错误留页处理。
- F34 录音会话未结束时禁用清空全部数据并说明原因；安全缓存清理仍可使用。SDK 在录音操作锁内检查存储维护，并通过 SDK 实例内共享协调器排斥与导入、裁剪、增强、导出和分享准备并发的清缓存/清空数据操作。隐私页同样显示操作繁忙提示。
- S0 冻结了 F11、后台开关、权限、存储、后续库/设置与未开放 Pro 的行为边界；反馈地址及后续筛选等无事实依据的产品项保留待定。

## 验证

- `:soundly-app:assembleDebug`、App/SDK 单元测试、App lint 通过。单元测试覆盖退出前暂停、重建、会话变更、防误丢弃、后台开关、维护与音频工作互斥及取消后释放。
- Android 13 模拟器：真实 SDK 录音验证 F11 两个按钮、页面重建后确认、返回保持暂停、关闭后台时切后台暂停、存储页禁止清空及按会话放弃；另验证公共导出进行时不能清缓存。录音、导入到导出主流程及既有入口回归通过。
- SDK 录音、存储、导入恢复和导出仪器回归 33 项通过，含过期 session 操作、低空间、中断与恢复等。F11 截图使用模拟器产生的测试录音：[浅色](screenshots/S1-F11.png)、[深色](screenshots/S1-F11-dark.png)。

## 边界

- 前后台识别使用应用 Activity 生命周期和 700 ms 防抖；真实设备在来电、权限撤销、系统强制终止、锁屏及厂商后台限制下仍需 S6 真机验证。系统通知由 Android 渲染。
- 存储协调器作用于当前 SDK 实例和本进程；多进程或额外独立 SDK 实例的跨进程存储维护不在本次保证范围。清理后已分享给外部应用的临时副本可能不可再访问。
- F12/F13 使用真实状态和公共组件，F14 延续现有恢复界面；设计稿中的复杂图形/精细视觉与全面真机验收仍应在 S6 对照核验。F26～F29、F32～F37、F20/F21 专题分别由 S2～S5 实施。
