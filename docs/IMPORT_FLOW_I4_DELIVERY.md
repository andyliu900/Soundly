# I4 交付记录：增强与版本对比

## 实现范围

- F18～F23 使用预览页当前选择的版本作为本次增强输入；裁剪后进入增强时，设置页和进度页标识裁剪版本。失败、取消或任务不可用时返回实际输入的预览上下文，保留当前选中版本。
- 结果页核对增强版本属于当前项目、类型为增强且来源 ID 指向本次输入；无法验证对应关系时显示不可用，不回退到其他版本。已保存选择如不属于本次配对，恢复为增强版本。
- AB 对比使用本次输入与其增强输出；裁剪输入显示“处理前”和“裁剪音频”，导入来源使用音频文案，录音原版保留既有录音文案。波形按所选版本生成或读取。切换时保留可用的播放位置，目标较短时限制在目标时长内；切换失败恢复原播放器与选择。
- 导出入口传递当前对比选中的版本 ID，创建另一增强版本沿用本次输入。增强失败、取消及结果未知的提示要求在必要时检查录音库。
- SDK 在数据库版本提交开始后不再删除结果不明的输出，避免提交已成功但协程被取消时破坏版本文件。

## 验证

- App 和 SDK 单元测试、Debug 构建、App lint 通过；单元测试覆盖输入/输出来源不匹配、无效恢复选择、切换到更短版本、切换失败及任务恢复。
- Android 13 模拟器使用真实 WAV：导入原版、裁剪版分别从页面启动增强，验证输出来源、AB 播放切换、两个选项各自进入导出的版本 ID；验证任务不可用时回到原预览及裁剪版本。
- 录音来源增强及 AB 导出、裁剪和主流程仪器回归；SDK AudioEditingTest 覆盖真实操作和提交后抛取消时保留已入库音频。

## 限制和后续工作

- 处理前后的对比位置基于双方各自的播放时间，目标时长较短时会截断到其末尾；Android 播放器的 seek 和编码帧精度决定实际听感，不承诺采样级同步。
- 对缺少来源 ID 的旧增强版本，无法证明配对关系，因此不会在本次结果页中作为可对比结果展示。结果未知时应先检查录音库；提交状态不明可能保留未被数据库引用的文件，后续存储清理需识别引用后处理。
- 导出/分享/录音库闭环和版本标签已在 I5 实施；I6 仍需真实设备、多编码格式、系统文件选择器及无障碍验收。本阶段模拟器验证不代表这些验收已完成。
