# S0 次要流程行为契约

日期：2026-11-16。按现有设计和代码作为本轮实施基线；没有产品事实支撑的商业和反馈细节保持待确认。

| 范围 | 本轮规则 |
| --- | --- |
| F11 放弃录音 | 从正在录音退出先暂停，暂停成功后显示两个操作：返回录音、放弃录音。返回后保持暂停，由用户手动继续或保存；系统返回/点击遮罩等同返回录音。暂停失败不展示已暂停假象、不丢弃。操作与会话 ID 绑定，重建不得对另一会话执行放弃。 |
| F10 后台 | 后台开关开启时使用前台服务及通知，通知权限拒绝不等于麦克风被拒绝。关闭时，应用整体转后台后暂停录音；回前台不自动继续。界面重建和应用内页面切换不视为进入后台。后台暂停失败须回到应用后告知。 |
| F12/F13 | 使用 SDK 真实原因；中断可重试或保存，空间不足可打开存储管理。释放空间不自动恢复；从存储管理返回原录音状态。执行时禁止删除全部数据，允许安全的缓存清理。 |
| F14 | 按指定 session 恢复并保存或确认放弃；不假定可继续录制。失败留页，多个会话逐个处理。 |
| F05/F06 | 普通拒绝可重试，系统不再允许请求时引导到设置；导入不要求麦克风权限。从设置返回只检查授权，不自动启动录音。 |
| 存储操作 | 当前录音会话未结束时不得清空全部数据，录音保存或增强正在处理时不得清理其临时缓存；SDK 通过共享操作协调器阻止维护与导入、裁剪、增强、导出及分享准备并发，并与录音操作互斥。 |
| F26～F29 | 筛选采用设计稿四项：全部、含增强版本、未增强的录音项目、导入项目；分类可交叠，搜索按标题过滤。单版本删除不在现有设计范围，保留项目整体删除。 |
| F28 编辑来源 | 详情选择的版本用于试听、裁剪、增强和导出；裁剪成功返回详情并选择新版本，取消保持原选择；标记仅在版本来源链可追溯时映射到当前时间轴。 |
| F20/F21 返回 | 保留触发本次增强的实际来源及输入版本；失败、取消、换模式之后仍回同一详情或预览。任务进程中断时提示检查已生成版本，不自动重试。 |
| F32/F33 | 录音格式以 SDK 支持的 M4A/AAC 为准，输出格式不得包含 UNKNOWN；设置界面能力过滤和返回体验属于 S4。 |
| F35/F36 | 隐私数据范围以实际 SDK 行为为准；邮件地址未提供前不虚构，诊断信息只在用户确认后加入邮件草稿。对应页面完善属于 S4。 |
| F37 | 只展示未开放购买，不加入购买或恢复购买。 |

F11 的两按钮决定遵循现有 F11 稿，取代 H4 临时三按钮方案。F12/F13、保存和恢复过程缺少独立详细状态稿，沿用公共 Material 状态和文案，不把系统通知绘制成自定义通知。S2/S3/S5 实施情况与验收限制见 [交付记录](SECONDARY_FLOWS_S2_S3_S5_DELIVERY.md)；S4 实施情况见 [交付记录](SECONDARY_FLOWS_S4_DELIVERY.md)；S6 仍按里程碑推进。
