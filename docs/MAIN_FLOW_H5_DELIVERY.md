# H5 交付：原音预览与增强入口

## 实现范围

- F15 使用项目和明确的版本 ID 观察真实数据，加载 SDK 静态波形及项目标记，播放、暂停、定位、播放结束和播放错误由 SDK 状态驱动；波形缺失时提示并保留播放能力。标记可点击定位。页面离开时暂停当前预览。
- F16 校验去空白后的非空名称和 50 字符上限，保存完成后才关闭；失败保留输入并提示。项目变更通过仓库 Flow 回显。
- 一键增强使用 `EnhancementMode.default` 创建任务；调整方式传入同一项目与来源版本。两个入口共用 `StartEnhancementUseCase`；提交中禁重复和返回，任务 ID 保存在页面状态中以支持重建后的导航。更多菜单提供裁剪和直接导出已有入口。
- 页面重建不重放启动操作，显式指定的版本不存在时显示错误，不以原音替代。

## 验证

- `:soundly-app:testDebugUnitTest`、`:soundly-app:assembleDebug`、`:soundly-app:assembleDebugAndroidTest`、`:soundly-app:lintDebug` 通过。
- API 33 模拟器：使用 SDK 保存真实 WAV 项目，验证播放、重命名的持久化、调整方式的版本参数、一键增强进入任务界面；公共播放器和顶部栏回归测试通过。
- 单元测试覆盖版本缺失、波形及播放操作使用指定版本、定位、名称校验、重复提交和已创建任务的重建恢复。

## 后续边界

- F18～F23 的完整视觉、增强任务状态与进程终止后的恢复属于 H6；F24/F25 的完整保存与分享属于 H7。一键入口目前进入已有增强进度页面，其完整异常和终态体验尚未按 H6 验收。
- SDK 静态波形是单独持久化的数据；缺少波形文件的导入或派生版本会提示波形不可用，不生成虚假波形。录音生成的波形及不同设备的真实录放音体验仍需真机验收。
