## F18 增强方式页面设计还原

- 重新排布录音摘要、推荐说明、四种模式卡片及固定底部操作区，标题为“增强录音”；根据应用昼夜主题切换背景、卡片、文字及系统栏图标。内容区可滚动，底部操作保持可见。

- 四个选项使用带原生单选语义的完整卡片，选择会保存在页面状态中。启动任务时仍传递所选模式和明确的输入版本；任务提交期间禁用模式、试听及开始按钮，防止重复操作。
- 推荐卡只说明自动模式的适用范围和处理方向，不显示未经检测的音频分析结论。
- `docs/screenshots/F18-enhancement-setup-light.png` 与 `F18-enhancement-setup-dark.png` 为仅存在于 debug 构建的示例数据预览，复用生产布局与渲染器，不代表真实录音或 SDK 任务。
- 构建、单元测试和 lint 通过；API 33 模拟器 8 项相关设备测试通过，覆盖昼夜主题、四种模式切换、重建后选择保留、真实播放器触摸及无障碍定位、按所选模式提交实际 SDK 任务，以及预览、结果与公共顶部栏回归。

- F18 显示项目及输入版本、波形和播放器，提供四种产品模式；选择保存于页面状态，提交仍复用 H5 的单次任务启动和 preset 映射。缺失版本时不允许提交。
- F19～F21 从 SDK 观察实际阶段和百分比；返回与取消按钮均走取消确认。取消和重试期间互斥，失败按 SDK `retryable` 决定是否提供重试，重试切换到新的 taskId。未知任务提供可恢复提示；完成与取消只在页面处于前台时处理，并移除进度页面，避免返回时重复处理终态。
- F22/F23 明确区分本次输入与增强版本，展示实际处理模式及方向，选中版本决定导出参数。两版本使用真实项目与波形，播放中切换保留时间和播放状态；切换失败保留原选择并尝试恢复播放器。缺少明确指定的版本时展示错误。另一个版本从本次输入进入设置。
- taskId、项目与输入版本随导航保存；SDK 仅支持进程内任务观察，进程终止后的未知任务会提示中断并支持回到输入录音，不会自动重新提交。

验证：`:soundly-app:testDebugUnitTest`、`:soundly-app:assembleDebug`、`:soundly-app:assembleDebugAndroidTest`、`:soundly-app:lintDebug` 通过。API 33 模拟器使用真实 SDK WAV 项目完成增强并验证结果页、播放中 AB 切换与导出版本；也验证未知任务重建恢复，并回归 F15、顶部栏和播放器，共 7 项设备测试。单元测试覆盖切换失败回滚、缺失版本、重试切换 taskId、取消互斥及不可重试错误。

限制：增强后静态波形是否可用由 SDK 持久化能力决定，缺失时页面提示，不绘制虚假波形。不同设备的音频焦点和前后台切换仍需真机验收。F24/F25 保存与分享交互已在 H7 接入，详见 [H7 交付记录](MAIN_FLOW_H7_DELIVERY.md)。
