# S6 联调和验收记录

日期：2026-11-17。范围为 S0～S5 及两条主流程；本次完成自动化与模拟器联调，真机验收仍待执行。

## 本次修复

- 项目删除由详情 ViewModel 管理，确认后跨 Activity/视图重建保持单次操作；SDK 在文件暂存、数据库删除和清理期间屏蔽协程取消，避免页面退出使项目文件停留在暂存状态。进程突然终止、系统掉电等不属于协程取消，仍需另外验收。
- 流式解码器将 `CancellationException` 原样传播，避免真实增强取消被包装成解码失败；真实 WAV 增强测试覆盖继续、确认取消、返回详情和原始文件保留。
- 录音库长标题与状态标签在大字体下不再互相挤压；无结果状态不再被悬浮录音按钮遮挡。横屏提供搜索/筛选与列表双栏，录音与导入入口放在标题区。
- 进程重启专用仪器测试增加显式 opt-in，普通全量回归不再依赖测试运行顺序；独立按准备、强停、恢复顺序执行。

## 流程与验证

| 流程 | 自动化/模拟器验证 | 边界 |
| --- | --- | --- |
| 重命名、裁剪 | 项目详情重命名、真实 WAV 裁剪、选择新版本、重建、导出；SDK WAV/M4A 裁剪回归。 | AAC/MP3 暂不支持裁剪；M4A 按音频帧对齐。 |
| 后台录音、放弃 | Android 13 模拟器真实录音、放弃确认、后台暂停、会话重建、存储保护；SDK 录音及通知会话测试。 | 来电、锁屏、蓝牙变化、厂商后台策略及通知权限变化仍需真机。 |
| 录音库、版本、删除 | 搜索筛选、试听、取消和确认删除、导出副本保留；删除确认后立即重建；仓储测试覆盖文件暂存后取消。 | 删除清理阶段真实进程死亡/掉电恢复未验证；外部导出副本由系统或用户管理。 |
| 设置、隐私、帮助、Pro | 设置选项过滤、保存与重建、隐私到存储、FAQ 状态、诊断默认关闭；App/SDK 单元测试。 | 反馈收件地址尚未提供，邮件客户端实际兼容性和发送由用户确认。 |
| 权限、中断、存储、恢复 | SDK 录音、中断、存储互斥和导入恢复仪器测试；导入复制期间强停进程后确认清理并标记中断；另外分阶段验证待提交与已提交状态恢复。 | 真机的权限撤销、磁盘耗尽、真实来电及系统进程终止仍需验收。 |
| 增强取消、失败 | 状态机单元测试、真实文件增强成功和取消、未知任务恢复及详情返回。 | 增强进程被强停时结果仍可能不明，需检查项目版本；真实设备的任务失败/中断边界仍需验收。 |
