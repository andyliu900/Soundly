# H4 录音、保护与本地保存交付

> 后续 S1 已将 F11 临时三按钮方案调整为设计稿的两按钮方案，并补充后台与会话保护；见 [S1 交付记录](SECONDARY_FLOWS_S1_DELIVERY.md)。

## 功能范围

- F08/F09/F38：录音页订阅 SDK 的状态、时长、大小、标记及实时波形；波形缓存有界，暂停后冻结；支持标记、暂停、继续、结束并保存。浅色与深色共用状态逻辑。
- F10：保留 SDK 前台服务通知，支持暂停、继续、停止并保存及点击返回。通知按秒更新并在状态变化时更新，避免系统通知限流；通知启动的保存与服务销毁解耦，保存结果回交应用。
- F11：顶部和系统返回共用确认，保留返回录音、保存和放弃三项；保存及放弃执行中防止重复操作。
- F12/F13：按 SDK 的真实中断原因提示重试或保存；空间不足时提供存储管理入口，不展示虚构的剩余容量。
- F14：展示 SDK 持久化的会话名称、场景、格式、标记数、时长和文件大小；支持恢复、稍后处理、确认后按 sessionId 放弃。多个残留会话在放弃后逐个处理；失败留页。
- SDK 增加按 ID 放弃恢复会话、活动配置及进程内完成结果接口；保护活动会话和已保存项目，并在处理失败会话时保留可恢复内容。

## 阶段边界

F15 预览仍为既有功能界面，高保真与播放交互属于 H5；增强、导出及完整主流程验收属于 H6～H8。实际来电、设备断连、空间不足以及各厂商后台策略仍需真机验收；通知外观由系统渲染。恢复页不伪造实时波形或磁盘剩余量。
