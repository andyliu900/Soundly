# I5 交付记录：导出、分享与录音库

## 实现范围

- F24/F25 根据真实项目来源与版本类型标识原始录音、原始音频、裁剪版本或增强版本；裁剪版本的默认导出文件名带有“_裁剪”。实际名称、格式和大小采用 SDK 返回的保存结果，文件不存在或来源版本缺失时不会静默替换为其他版本。
- 保留 SDK 的格式能力、文件名校验、同名编号和平台存储处理。分享明确使用录音库中所选的源版本；导出时选择的格式不改变分享文件。打开分享面板不代表发送成功。
- 增加统一的版本标签：录音库显示中文来源和版本数，项目详情按创建时间及 ID 稳定排序，标示各版本编号、格式、时长及其直接来源；可选择版本、试听并重新打开预览。项目刷新或页面重建后保留选择，离开或切换版本时暂停详情页的试听。
- 保存完成后可返回录音库，返回栈清除导出页。导出记录用于恢复结果并避免自动重复保存；导出调用失败但目标状态不确定时保留待确认记录，提示用户先检查下载目录，再自行决定是否重试。

## 验证

- Debug 构建、App/SDK 单元测试和 App lint 通过。单元测试覆盖裁剪版的文件名和版本 ID、待确认导出记录、格式能力、名称、恢复与防重。
- Android 13 模拟器使用真实导入 WAV、裁剪版和增强版逐一导出，检查版本标签、实际名称与格式、文件字节、分享 URI 和读取权限，验证保存页面重建、回库、来源关系、选中版本重建及重新打开；同时回归录音导出、导入增强和主流程。
- Android 13 SDK 导出仪器测试 9 项通过，覆盖 M4A 到 WAV 等能力；Android 8 模拟器回归录音版本导出、分享及回库。Android MediaStore 可能将 WAV MIME 显示为 `audio/x-wav`，内容仍按 WAV 校验。

## 限制和后续验收

分享文件是所选源版本的临时副本，并非保证分享刚才转换后的导出文件。目标文件可能已发布但结果尚未记录，用户需检查下载目录；系统分享面板也无法证明对方已收到文件。I6 仍需覆盖真实设备、不同系统和解码器、系统/云文件选择器、进程终止和无障碍验收。
