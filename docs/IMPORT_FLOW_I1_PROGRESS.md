# I1 导入入口与可靠导入交付记录

日期：2026-11-16。I1 已实现；F30 高保真预览、导入波形及 F17 裁剪分别属于后续 I2/I3。

## 实现

- 首页、麦克风权限拒绝页及录音库使用同一个导入页面和 Android 系统文件选择器；取消选择返回调用页。导入不申请麦克风权限，执行中防重复并阻止返回，展示不确定进度。
- App 在发起导入前同步保存随机操作 ID；SDK 将操作、项目及版本关联写入 Room。操作记录使用主键及项目唯一索引；项目、原始版本和完成状态在同一数据库事务中提交。重复提交同一 ID 返回原结果，不创建第二个项目。
- SDK 使用进程内互斥和文件锁协调同一设备上并发调用。重启后按操作 ID 检查数据库与本地音频：已提交且文件可读则恢复结果；未提交的自有副本清理后提示重新选择；数据库失败或结果不明时保留文件并提供重新核验，不自动重导。授权失效需用户重新选择，不假定可持久读取原 URI。
- 复制到 App 私有目录后不依赖原 URI。导入过程中出现失败会先核验提交状态；文件和数据库不是同一事务，目录创建成功与所有权阶段写入之间若发生极端进程终止，可能保留一个空目录，后续不会将其误认为已导入项目或盲目删除。
- Room 从版本 4 升级至 5，增加导入操作表及可空的来源显示名；仅保存 provider 提供的显示名，不用 URI 尾段或项目名冒充。旧项目名称不变，来源显示名为空。旧 SDK 导入接口仍保留。
- 导入成功暂时携带明确的项目和原始版本 ID 进入现有音频预览，I2 再替换为 F30 视觉。现阶段不承诺真实百分比、后台续跑或取消导入。

## 验证

- App 与 SDK 单元测试、Debug 构建及 App lint 通过。
- Android 13 模拟器：SDK 导入、数据库迁移和既有编辑回归 26 项通过；App 导入、系统选择器取消、录音主流程、顶部栏和导出回归 7 项通过。另行测试麦克风未授权时从权限拒绝页进入导入，通过 1 项。
- Android 8 模拟器：SDK 导入与迁移 11 项、App 导入 3 项通过。
- Android 15 模拟器：SDK 导入与迁移 11 项，App 导入与顶部栏 5 项通过。
- 已使用独立仪器测试进程保存“文件已就绪但未提交”和“已提交”两种状态，在两次测试进程之间执行 force-stop；重新进入后分别验证安全清理与恢复已提交结果。这是对持久边界的模拟，不等同于在真实设备上随机时刻杀死正在复制的进程。
- App 启动时以已提交的待恢复操作为输入，验证自动进入预览且项目、原始版本 ID 与真实提交结果一致，消费后清除待恢复记录。
- 并发相同操作、数据库异常、提交事务回滚、缺失文件、权限拒绝、重启后结果恢复及旧库迁移均有针对性测试。云文档提供者、实际设备在复制中被系统终止的行为，以及 I2 以后的完整导入→编辑→导出体验仍需在后续设备验收中验证。
