# I2 导入音频预览交付记录

日期：2026-11-16。F30 基于已有预览 Fragment/状态机按项目来源渲染，与 F15 共享播放、定位、重命名、导航和固定顶部栏；不复制导入或音频处理业务。

## 实现

- 导入项目显示 F30 成功提示、项目名、导入时间、来源文件名、格式、时长、大小、波形及播放器，适配浅色和深色。来源显示名由 I1 的 provider 元数据提供；旧项目或 provider 未提供时显示“来源文件名不可用”，重命名只修改项目名。
- 提供首尾裁剪、增强方式、保存与分享和返回录音库入口，全部携带当前项目和版本；WAV/M4A 可进入现有裁剪页，AAC/MP3 明确提示当前不支持直接裁剪。F17 的高保真与完整裁剪交互属于 I3。
- SDK 对导入版本按需生成真实静态波形并原子缓存，读取前验证项目及版本；生成在 IO 线程串行去重，输入时长不准确时自适应归并以限制峰值数量。缓存损坏时重新生成；失败可在页面重试，播放与导出不依赖波形。
- 页面重建恢复项目和选择，不重新导入。播放/暂停、定位、重命名错误与增强导航复用既有状态机；所选版本不存在时显示错误，不切换到别的版本。

## 验证

- App 与 SDK 单元测试、Debug 构建及 App lint 通过；单测覆盖导入波形失败后播放仍可用、重试使用当前版本。
- Android 13 模拟器对真实导入 WAV 生成并缓存非零波形，验证播放、重命名不修改来源名、页面重建及裁剪/增强/导出版本 ID；连同 I1、F15、增强、导出、顶部栏和录音主流程，共 16 项仪器回归通过。
- Android 8 模拟器在 1.3 倍字体下验证 F30 操作；Android 15 模拟器验证 F30、缓存损坏后重建及顶部栏。
- [浅色截图](screenshots/F30-imported-light.png)和[深色截图](screenshots/F30-imported-dark.png)使用模拟器生成的测试音频；测试音频为恒幅正弦波，所以波形峰值接近一致。

真实设备、不同编码器和云文档提供者仍需 I6 验收。M4A/AAC/MP3 波形依赖设备解码器，解码失败会提示而不会伪造波形。F17 的高保真、精细选区与返回栈修正已在 I3 实施，详见 [I3 交付记录](IMPORT_FLOW_I3_DELIVERY.md)。
