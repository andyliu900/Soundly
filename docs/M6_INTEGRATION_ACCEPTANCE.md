# Soundly M6：第一阶段集成与稳定性验收

状态：**代码集成完成；真机验收待执行。**

本文件是 Material 功能版进入 M7 前的验收记录。它不将编译通过等同于设备行为通过：录音、权限、通知、文件选择、邮件与真实存储操作均必须在 Android 真机或模拟器上复验。

## 已完成的集成修正

- 录音库的空状态和正常状态均可新建录音或走系统文件选择器导入。
- 项目详情可对所选原始／派生版本播放，并打开该版本的预览、裁剪、增强和导出链路。
- 预览页按导航传入的 `variantId` 解析并使用对应版本，不再固定回退到原始音频。
- 新录音改用 SDK `prepareUsingDefaults()`，因此 F32 的录音设置对后续录音真实生效。
- F34/F35 的清缓存和删除本地数据都经 SDK `StorageManager`，不可逆操作都有 App 确认对话框。

## 真机执行顺序

1. 安装 `soundly-app/build/outputs/apk/debug/soundly-app-debug.apk`，首次启动完成 F01-F07；分别验证允许和拒绝麦克风权限。
2. 录制至少一段有标记的音频：依次验证 F08-F16、退出后恢复 F14，以及通知控制 F10。
3. 对该项目裁剪、增强、AB 试听、导出和分享，验证 F17-F25；导入一份 WAV/M4A/MP3 验证 F30。
4. 进入录音库验证 F26-F29；删除一个测试项目，确认已导出的文件仍存在。
5. 修改录音／输出设置，重启应用后新建录音；验证 F31-F38，最后使用测试数据验证清缓存与删除全部本地数据。

## M6 退出条件

- 上表全部“待设备验收要点”在至少一台 API 26+ 设备上通过并记录设备型号、Android 版本与 APK 版本。
- Android 13+ 设备额外通过通知授权和后台录音通知检查。
- 至少一种导入格式和一次下载目录导出成功；无崩溃、ANR、文件残留或项目库不同步。
- 不把 F37 购买能力纳入本阶段；其真实 Google Play Billing 验收属于商业化范围确认后的独立工作。
