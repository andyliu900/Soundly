# S0、S2、S3、S5 实施记录

日期：2026-11-16。行为基线见 [S0 契约](SECONDARY_FLOWS_S0_CONTRACT.md)。

| 阶段 | 实施内容 |
| --- | --- |
| S0 | 明确库筛选、版本操作、删除以及增强异常的来源返回规则。 |
| S2 | F26～F29：录音库搜索、四类筛选、空状态、列表试听、录音与导入入口；项目详情展示并选择版本、播放波形和标记，支持项目删除确认和失败反馈。删除项目不会删除已经导出的文件。 |
| S3 | 预览和详情共用重命名；详情可对所选版本裁剪，成功后返回详情并选中新版本，取消保留选择；版本波形按需生成。 |
| S5 | F20/F21 取消确认与失败状态；保存增强来源及输入版本，取消、失败返回或更换方式后仍指向实际来源。结果页继续创建版本时也传递来源。任务结果不明时提示检查，不自动重跑。 |

筛选中“已增强”包含有增强版本的项目，“原始录音”指尚无增强版本的录音项目，“已导入”按项目来源判断，因此分类可能重叠。列表试听项目的原始版本；项目详情中各操作使用当前选中的版本。详情标记通过版本来源链及裁剪起点映射，来源无法追溯时不显示可能误导的标记。现有设计没有单独删除版本的操作，删除作用于整个项目。

裁剪能力以 SDK 实际支持为准：WAV 和 M4A 可用，M4A 边界按音频帧处理；独立 AAC/MP3 暂不支持。增强进程中断后结果可能不明，需检查版本列表。详情及录音库页面使用主题色资源，但当前模拟器截图仅覆盖浅色主题，视觉仍需与设计稿逐项验收，尤其是录音库底部入口的布局。

已执行 App 和 SDK 单元测试、App lint、Debug 构建，以及 Android 13 模拟器上的 9 项录音、导入、增强、导出、裁剪、录音库和详情回归。覆盖详情重命名、裁剪后选择与重建、未知增强任务返回，以及项目删除后保留导出文件。F20 弹窗的真实运行中取消、真实进程中断、删除过程中的页面重建、深色主题、大字体及真机兼容性仍需在 S6 中专项验收；模拟器测试不能代替真机验证。S4 设置相关工作和 S6 综合验收不属于本次交付。
